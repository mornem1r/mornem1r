## Проекты

### [stepanov-campaign](https://github.com/mornem1r/stepanov-campaign)
> Официальный сайт предвыборной кампании

Полноценный предвыборный сайт, написанный на **Next.js 14 + TypeScript**. Включает биографию кандидата, программу, форму для пожертвований с интеграцией **Tinkoff Acquiring API** и раздел контактов.

**Стек:** `Next.js` · `TypeScript` · `Tinkoff Pay` · `Vercel` · `CSS Modules` · `GSAP анимации`

---

### telegram-bot *(в составе кампании)*
> Бот для сбора заявок на вступление в команду

Telegram-бот для автоматического сбора заявок от волонтёров и сторонников. Хранит данные пользователей, обрабатывает обращения и ведёт статистику активности.

**Стек:** `Node.js` · `Telegraf` · `In-memory store`
